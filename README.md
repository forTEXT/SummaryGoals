# SummaryGoals: Using LLMs to Extract Character Goals from Narrative Summaries

This repository contains code, data, and prompts for the paper "SummaryGoals: Using LLMs to Extract Character Goals from Narrative Summaries" published in the proceedings of CHR 2027: Computational Humanities Research Conference, 2027, Manchester, United Kingdom.

**Authors:** Julian Häußler, Evelyn Gius

**Institution:** *fortext lab*, Technical University of Darmstadt, Germany

Reference: Häußler, J., Gius, E. (2027). SummaryGoals: Using LLMs to Extract Character Goals from Narrative Summaries. CHR 2027: Computational Humanities Research Conference, January 5 – 8, 2027, Manchester, United Kingdom.

GitHub Repository: https://github.com/forTEXT/SummaryGoals

# Repository Contents

```
├── README.md
├── code            	
│   └── py	    				    <- python files used on a GPU server, requires ollama
│   └── ipynb	    					<- jupyter notebooks used to further analyze data
├── data				
│   └── results		    		
│		└── goal_extraction_LLMs	  <- goal extraction with LLMs
│		└── goal_extraction_manual	<- manual analysis
│		└── qualitative_evaluation	<- qualitative evaluation of the goal extraction with LLMs
│		└── question_answering		  <- question answering evaluation
└── prompts							    <- prompts used for goal extraction and evaluation
```
